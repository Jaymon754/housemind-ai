# HouseMind AI — AI 技术说明

> 本文记录模型、数据、解释、RAG、Agent 与视觉能力的真实实现与边界。所有指标由仓库脚本生成，可在 `ml/artifacts/` 复核。

## 1. 问题定义

给定一套金县住宅的结构、位置与状况特征，输出：

1. 成交价点估计；
2. 80% 参考区间（P10–P90）；
3. 每个特征对价格的加性贡献；
4. 同邮编可比成交与市场位置；
5. 在给定租金、首付、利率与持有假设下的现金流与回报；
6. 带引用的方法解释。

主模型只回答“在 2014–2015 年金县成交样本中，这套房的特征组合对应什么价格中枢”，不回答“现在值多少钱”。

## 2. 数据

### 2.1 King County

- 原始 21,613 行 × 21 列。
- 清洗：去除重复 177 行、异常/缺失目标与关键特征，保留 21,418 行。
- 目标：`price`，2014-05 至 2015-05 成交价，未做通胀调整。
- 划分：80/20 随机 holdout，训练 17,134 / 测试 4,284，`random_state=42`。
- 特征 22 个：卧室、卫浴、室内面积、土地面积、楼层、滨水、景观、状况、等级、地上/地下面积、建造年份、翻新年份、经纬度、周边面积、房龄、是否翻新、容积率代理、卫浴卧室比、邮编市场基准价。

### 2.2 特征工程

- `house_age = sale_year - yr_built`（下限 0）。
- `has_renovated = yr_renovated > 0`。
- `living_lot_ratio = sqft_living / sqft_lot`。
- `bath_bed_ratio = bathrooms / max(bedrooms, 1)`。
- `zip_market_value`：训练集按邮编计算平滑成交价中位数，**只在训练集拟合**，测试与新请求映射；未见邮编回退全局中位数。
- 区域规则：按经纬度划分西雅图北区/中南部/西岸、东区、北金县、南金县，用于误差切片与驾驶舱，不进入模型。

### 2.3 UCI 与 California

- UCI：414 行、7 特征，目标为单位面积房价（万元新台币/坪），2012–2013 新店区。用于小样本非线性与距离关系验证。
- California：20,640 行、8 特征，1990 年普查街区中位房价，目标在 500,001 美元封顶。用于区域模型对照与封顶偏差讨论。
- **不混训、不平均指标**；研究页分别展示并标注不可比。

## 3. 主模型

### 3.1 候选与选择

| 模型 | 角色 | 关键配置 |
|---|---|---|
| Ridge | 线性基线 | 标准化，alpha 由内层验证选择 |
| Random Forest | 非线性集成基线 | 400 棵树 |
| XGBoost | 最终模型 | 1200 棵上限，depth 6，lr 0.03，subsample 0.8，colsample 0.8，min_child_weight 3，早停 |

选择依据是测试集 MAE，而不是只看 R²。XGBoost 早停轮数 1200（达到上限，说明继续加树收益已很小）。

### 3.2 结果

| 模型 | MAE | RMSE | R² | MAPE | ±20% |
|---|---:|---:|---:|---:|---:|
| Ridge | $99,414.81 | $158,642.52 | 0.7916 | 20.45% | 61.6% |
| Random Forest | $64,051.47 | $113,126.89 | 0.8940 | 12.58% | 81.7% |
| XGBoost | **$59,477.26** | **$100,985.85** | **0.9156** | **11.91%** | **83.2%** |

- 相对 Ridge，MAE 降低 **40.2%**。
- 中位绝对误差 $37,147；±10% 内 58.2%。
- 训练集 17,134 行，测试集 4,284 行。

### 3.3 区间

采用 **5 折 out-of-fold 残差分位数**：

1. 训练集分 5 折，每折用其余 4 折训练同配置 XGBoost；
2. 对每折留出样本预测，收集 OOF 残差 `y - ŷ`；
3. 取残差 10% 与 90% 分位，作为区间下/上偏移；
4. 对新样本输出 `[ŷ + q10, ŷ + q90]`。

结果：

- q10 = **−$90,228.50**
- q90 = **+$86,241.87**
- 测试集覆盖率 **81.5%**（名义 80%）
- 中位区间宽度 **$176,470.37**

区间不对称，符合高价房右尾更长的残差分布。它只覆盖历史误差模式，不覆盖装修、景观、产权等结构性变化。

### 3.5 泛化

**未见邮编 GroupShuffleSplit（80/20）**：

- 训练 16,923 / 测试 4,495；
- 14 个邮编在训练中完全未出现；
- MAE **$95,130.23**，RMSE **$145,205.46**，R² **0.7814**。

冷启动误差比随机切分高约 60%，这是邮编基准回退的代价。研究页把它作为“下界”，而不是主指标。

**UCI holdout**：MAE **3.70**，R² **0.8305**，MAPE **11.59%**；5 折 CV MAE **4.76**。  
**California holdout**：MAE **$29,382.88**，R² **0.8472**，MAPE **16.87%**。

## 4. 可解释性

### 4.1 精确 TreeSHAP

使用：

```python
booster.predict(xgb.DMatrix(X), pred_contribs=True)
```

- 最后一列为基准值，其余列为每个特征的贡献。
- 对树模型，这是精确 Shapley 值，不是采样近似。
- 避免 `shap` 包与 XGBoost 版本转换时出现的数组解析问题。

### 4.2 全局与局部

- 全局：测试集每个特征的平均绝对贡献，写入 `global_shap.json`。
- 局部：单套房源的贡献排序，Top 8 + 其他。
- 校验：`base + Σ contributions ≈ prediction`，测试中断言误差 < 1 美元。
- 展示：同时给特征值、贡献金额、方向；使用中性色表示负贡献，避免污名化。

### 4.3 常见误读

- SHAP 不是因果效应；
- 不使用受保护字段不等于公平；
- 贡献是相对基准的偏离，不是绝对价格；
- 全局重要不等于局部重要。

## 5. RAG

### 5.1 语料

- 18 篇 Markdown 方法文档，71 个片段。
- 主题：估值方法、比较法、SHAP、租金回报、DSCR、月供、交易流程、尽调、持有成本、租赁管理、市场分析、公平住房、AI 安全、视觉边界、中国政策、1031、保险、市场周期。
- 每篇有 `title/category/source_name/source_url/updated`，回答可追溯。

### 5.2 检索

- 切分：按标题层级与段落，约 500–900 字/片段，保留章节名。
- 向量：512 维 signed feature hashing，token 为拉丁词 + 中文单字/双字 + 数字；L2 归一。
- 字面：BM25，原词与同义词扩展两路。
- 融合：
  `0.46 * vector + 0.27 * bm25 + 0.17 * expanded + 0.14 * title_coverage + domain_bonus`
- 领域词加权：DSCR、Cap Rate、NOI、IRR、SHAP、AVM、PMI、1031、MAE、R²、提示词注入等。
- 多样性：同一文档最多 2 个片段。
- 拒答门槛：查询必须包含至少一个特定双字/拉丁术语并与语料重叠；否则返回空结果。避免“如何更换汽车轮胎”命中“更换”这类泛词。

### 5.3 回答

- 有 DeepSeek 密钥：把 Top 片段作为上下文，要求只基于材料回答并标注 `[n]`。
- 无密钥：本地抽取式回答，按查询词覆盖选句，固定免责声明。
- 引用：每条结果带标题、章节、来源名、URL、类别、分数。
- 数字与结论不得超出片段；无结果时明确说“没有找到”。

### 5.4 评测

`ml/evaluate_rag.py` 使用 20 个领域问题与 4 个超纲问题：

- Hit@1 = 20/20，Hit@3 = 20/20，Hit@5 = 20/20；
- 超纲拒答 = 4/4；
- 判定：期望术语出现在 Top-k 的标题、章节或正文。

这是一个小型、人工检查的内部 gold set，不是开放域 benchmark；问题数量少，不能外推为通用 RAG 能力。

## 6. Agent

### 6.1 工具

| 工具 | 作用 | 关键输出 |
|---|---|---|
| `predict_house_price` | 估值 | 价格、区间、单价、市场、驱动 |
| `explain_house_price` | 归因 | SHAP、what-if、可比 |
| `analyze_market` | 区域市场 | 邮编统计、趋势、库存代理 |
| `calculate_investment` | 投资测算 | 月供、NOI、DSCR、IRR、情景 |
| `search_property_knowledge` | 知识检索 | 片段、引用 |
| `analyze_house_image` | 图像观察 | 本地信号/远程语义、边界 |

### 6.2 两种模式

**DeepSeek Function Calling**

- OpenAI 兼容接口，`tools` 为 JSON Schema；
- 最多 6 轮工具循环；
- 工具结果回填后生成中文 Markdown；
- 输出经清洗、PII 脱敏、canary 检查。

**本地规划器**

- 规则解析：预算、邮编、面积、卧室、租金、首付、利率、持有期；
- 固定工具链：估值 → 归因 → 市场 → 投资 → 知识；
- 模板报告：结论、价格驱动、出租测算、风险、下一步；
- 同样发 SSE 事件、同样写数据库、同样可追溯；
- 界面明确显示 `LOCAL PLANNER`，不冒充 LLM。

### 6.3 安全

- 输入注入检测：忽略指令、系统提示、开发者模式、越狱、canary 等模式；
- 高危直接阻止并返回安全说明；中危降级模板；
- 输出清洗：移除 canary、密钥样式、HTML 脚本；
- PII：手机号（含无分隔符）、邮箱、SSN 样式；
- 限流：滑动窗口，默认 30 次/分钟；
- 工具参数强制转换：邮编 5 位字符串、数值范围、别名。

## 7. 视觉

### 7.1 本地模式

Pillow 计算：

- 平均亮度、过暗/过亮像素比例；
- 色温（R/B 比）与饱和度；
- 边缘密度（构图复杂度代理）；
- 主色板（量化聚类）；
- 可见观察：亮度、色偏、杂乱度；
- 明确边界：不判断房间类型、风格、材质、面积、结构安全、霉菌、电路、产权。

### 7.2 远程模式

- OpenAI 兼容 Qwen-VL；
- 只描述可见内容：空间类型、采光、材质、明显破损；
- 不输出结构安全、价格或法律结论；
- 置信度只在有语义模型时显示；本地模式显示“语义能力 · 未启用”。

## 8. 评测协议

- 固定随机种子，固定切分。
- 测试集只用于最终报告，不参与调参/早停。
- 区间覆盖率在测试集上单独计算。
- 泛化实验使用 GroupShuffleSplit，避免邮编泄漏。
- RAG gold set 人工编写，明确判定规则。
- 所有指标写入 JSON，前端只读，不在前端硬编码“好看数字”。

## 9. 失败模式与缓解

| 失败模式 | 表现 | 缓解 |
|---|---|---|
| 分布漂移 | 2015 后市场变化 | 明确数据截止；不做当前价声明 |
| 未见邮编 | 回退全局基准，误差升高 | 单独报告冷启动下界；提示补充可比 |
| 豪宅/独特物业 | 绝对误差大 | 区间 + 人工复核提示 |
| 图片误读 | 把亮度当质量 | 本地只给物理信号；远程只描述可见 |
| RAG 幻觉 | 无依据回答 | 拒答门槛 + 引用 + 抽取式兜底 |
| 注入 | 输出系统提示/越权 | 输入检测 + 输出清洗 + canary |
| 单工具失败 | Agent 中断 | 捕获异常，继续合成并标注缺失 |
