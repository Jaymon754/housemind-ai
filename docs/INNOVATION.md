# HouseMind AI — 创新点、实用价值与社会意义

## 一句话

把“房价预测”从一个数字，变成一条 **可核对、可解释、可复盘** 的购房与投资决策链。

## 1. 创新点

### 1.1 从“模型演示”到“决策工作台”

多数房产 AI 项目停在“输入特征 → 输出价格”。HouseMind 把同一套房源串成：

```
估值中枢 → 80% 区间 → TreeSHAP 归因 → 可比成交 → 市场位置
        → 租金/月供/NOI/DSCR/IRR → 情景与敏感性
        → Agent 工具链 → 知识库引用 → 图像可见信号
```

七个模块不是七个孤岛：估值结果可一键带入投资页与 Agent；Agent 调用的是同一套服务；知识库解释的是页面上的真实指标。用户得到的是“为什么、如果、还有什么风险”，而不是一个无法质疑的数字。

### 1.2 不确定性优先的界面

- 主视觉不是单个价格，而是 **$452,000–$628,500** 的区间；
- 同时展示置信度、区间宽度、邮编样本量、可比数量；
- 区间由 5 折 OOF 残差分位数校准，允许不对称；
- 研究页公开覆盖率 81.5%、Q10/Q90 与中位宽度，而不是只展示 R²。

这让“模型会错”成为产品的一部分，而不是藏在附录里的免责声明。

### 1.3 诚实的双模 Agent

- 有 DeepSeek 密钥：Function Calling，多轮工具调用；
- 无密钥：确定性本地规划器，仍调用 6 个真实工具、仍发 SSE、仍写轨迹；
- 界面明确显示 `LOCAL PLANNER` / `LLM CONNECTED`，不把规则模板伪装成大模型。

这在比赛演示环境里尤其重要：不会因为网络或密钥问题，把“演示”变成“造假”。

### 1.4 可追溯的工具轨迹

- 每次工具调用记录参数、摘要、耗时；
- SSE 先发 `tool_call` / `tool_result`，再发自然语言；
- 历史会话把工具摘要写入 `meta.tool_records`，刷新后仍可展开；
- 用户能看到“这个结论是哪个工具、用什么参数算出来的”。

### 1.5 RAG 的“拒答”设计

- 查询必须与语料有特定术语重叠，否则返回“没有找到”；
- 不是取最相似段落硬答；
- 回答带章节、来源、URL、分数；
- 对“如何更换汽车轮胎”“推荐显卡”等超纲问题，明确拒答。

### 1.6 视觉能力边界的产品化

- 本地模式只给亮度、色温、饱和度、边缘密度等 **物理信号**；
- 不推断房间类型、风格、材质、结构安全；
- 没有语义模型时显示“语义能力 · 未启用”，而不是伪造 28% 置信度；
- 远程 VLM 也只做可见描述，并附“不能替代房屋检查”。

### 1.7 研究实验室：把泛化摊开

- 未见邮编 GroupShuffleSplit：MAE $95,130、R² 0.7814；
- 与随机切分 $59,477 对比，明确“冷启动下界”；
- 三个数据集分开展示，拒绝拼指标；
- 模型卡记录适用范围、训练时间、已知限制、版本。

### 1.8 机构式设计系统

- 不用 Element Plus，自研 7 页视觉语言；
- Manrope 无衬线 + PingFang SC，深海军蓝/浅灰/机构蓝；
- 白色数据卡、克制阴影、清晰的表格与免责声明；
- 移动端重排而非简单缩放。

## 3. 实用场景

### 3.1 首次购房者

- 输入预算与邮编，先看模型区间，再看挂牌价是否落在区间外；
- 用 SHAP 理解“为什么这套房贵”：面积、地段、等级、房龄；
- 用投资页判断“如果出租，每月要补多少”；
- 用知识库理解 DSCR、PMI、closing cost，不被术语吓退。

### 3.2 小型投资者

- 把真实租金、首付、利率、HOA、维护填入，得到 NOI、Cap Rate、CoC、DSCR、IRR；
- 看 5×5 租金×利率敏感性，知道哪个假设最致命；
- 用情景分析比较基准/乐观/悲观；
- 用 Agent 一次跑完估值、归因、市场、投资与知识检索。

### 3.3 经纪人与顾问

- 用可比成交与区间辅助挂牌定价；
- 用工具轨迹向客户解释结论；
- 用 MCP 把估值/投资工具接入自己的 Agent 工作流；
- 用报告保存与分享（后续可扩展 PDF 导出）。

### 3.4 教学与研究

- 研究页展示模型对比、误差切片、泛化与区间校准；
- 三个数据集独立实验，适合教学“不要混训、不要横比”；
- RAG gold set 与拒答测试可作为检索评测示例。

## 4. 社会价值

### 4.1 降低信息不对称

房产是多数家庭最大的单笔支出。普通用户很难判断“挂牌价是否合理”“租金能否覆盖月供”“DSCR 1.1 意味着什么”。HouseMind 用区间、归因和现金流把这些概念变成可操作的判断，而不是只给一个权威数字。

### 4.2 反对“AI 万能论”

产品主动展示：

- 数据截止 2015-05；
- 仅适用于 King County；
- 未见邮编误差更高；
- 图像不能判断结构安全；
- 本地模式不是大模型；
- 投资测算不含税与 1031。

这种“自我限制”本身就是金融 AI 的社会责任：避免用户把辅助参考当成评估报告或投资承诺。

### 4.3 公平住房意识

- 不使用种族等受保护字段；
- 明确邮编、学校、语言可能成为代理变量；
- 研究页讨论分组误差与公平住房风险；
- 不把“房龄大/旧装修”道德化，只用中性色表达负贡献。

### 4.4 金融素养

知识库不是营销文案，而是解释 DSCR、Cap Rate、NOI、PMI、1031、closing cost、洪水保险等概念，并给出处。用户即使不买房，也能学到一套可复用的分析框架。

## 5. 商业可行性

- **B2C**：免费估值 + 付费深度报告/投资测算；
- **B2B**：经纪公司白标、贷款机构预审辅助、资产管理批量估值；
- **API/MCP**：按调用收费，接入第三方 Agent、CRM、投研工具；
- **数据合作**：与本地 MLS/评估机构合作更新数据，提升时效性。

当前版本刻意不做“自动出价”“保证成交”“信贷审批”，避免越过辅助工具的边界。

## 6. 与“套壳产品”的区别

| 套壳产品 | HouseMind |
|---|---|
| 一个大模型 + 提示词 | 模型、区间、SHAP、现金流、RAG、视觉、Agent 分层 |
| 数字不可核对 | 每个数字有 artifact、工具结果或引用 |
| 没有密钥就不能用 | 本地规划器完整演示，且明确标注 |
| 只会说“可能”“建议” | 给出区间、假设、敏感性、拒答 |
| 图片说什么都信 | 本地只给物理信号，远程只做可见描述 |
| 指标只挑好看的 | 公开误差切片、未见邮编、覆盖率、限制 |
