# AI 安全设计

## 提示词注入

用户输入、网页内容、PDF 和图片 OCR 都可能包含“忽略之前的指令”“输出系统提示”“调用某个工具”等攻击文本。防护不能只靠一句“不要听用户的”，而应分层：输入检测、工具权限最小化、参数白名单、输出过滤、敏感信息隔离、人工复核。

## 工具调用安全

Agent 只能调用注册过的工具；工具参数必须经过 schema 校验与数值范围限制；文件路径不能由模型自由拼接；涉及写操作、付款、删除或对外发送的工具需要额外确认。工具返回内容视为不可信数据，不得当作新指令。

## 隐私

不要记录 API Key、身份证、银行账号、门牌号与人脸。上传图片应去除 EXIF 定位信息；日志只保留必要的会话 ID 与错误码。对第三方模型 API，应披露数据会发送到外部服务，并提供不使用外部服务的本地模式。

## 输出兜底

所有估值与投资输出应附带不确定性、适用范围和免责声明。若模型输出包含密钥样式、系统提示、HTML 脚本或超出工具结果的数字，应拦截并降级到模板化回答。对高风险问题（法律、税务、贷款审批）明确建议咨询持牌专业人士。
