# 投资房回报指标

## 毛租金回报率

毛租金回报率 = 年租金收入 ÷ 购房总价。它计算简单，但没有扣除空置、税费、保险、维护和贷款，容易高估真实回报。适合作为第一层筛选，不应作为最终决策依据。

## 资本化率（Cap Rate）

Cap Rate = 净运营收入（NOI）÷ 物业价格。NOI 是有效租金收入减去运营费用，但**不扣除贷款本息**。Cap Rate 反映物业本身的盈利能力，便于同类型物业横向比较。低 Cap Rate 通常意味着市场预期增长较强或风险较低，也可能是价格过热；高 Cap Rate 可能意味着更高收益，也可能反映更高的空置、维护或区域风险。

## 现金回报率（Cash-on-Cash）

现金回报率 = 年度税前现金流 ÷ 实际投入现金。实际投入现金包括首付、 closing costs 和必要的立即维修。这个指标把杠杆纳入考虑，适合衡量“我实际投入的钱一年赚回多少”。如果月现金流为负，现金回报率会是负数，即使长期增值可能为正。

## 总回报与 IRR

总回报应包含持有期现金流、出售净得款和贷款摊还带来的权益增加。IRR 把不同年份的现金流折现，适合比较不同持有期的项目，但它对退出价格和租金增长假设非常敏感。展示 IRR 时必须同时展示假设，不能只给一个漂亮数字。

> 经验法则只能筛选，不能替代逐项测算。租金、空置、税费、维护和融资成本都要用本地证据校准。
